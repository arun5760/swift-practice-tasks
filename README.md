# Swift Programming Practice Tasks — Solutions

This repository contains standalone Swift solutions for the tasks in the supplied **Swift Programming Practice Tasks** document.

## Folder structure
- `Unit1_ControlFlow/` — control flow, operators, ranges, loops, and restaurant bill exercises.
- `Unit2_Collections/` — arrays, sets, dictionaries, collection algorithms, and practice activities.
- `Unit3_EnumStructClass/` — enums, structures, classes, inheritance, value/reference semantics, and mini-projects.

Each `.swift` file is intended to be run independently. Most tasks use sample values at the top of the file; change those values to experiment.

## Run a task
On a Mac with Swift installed, open Terminal in the repository and run, for example:

```bash
swift Unit1_ControlFlow/Task1_1.swift
```

You can also paste a single task into a Swift Playground or run it in Xcode. Some exercises use `Foundation` for formatting or mathematical helpers.

## Notes
- Task numbering follows the supplied worksheet.
- The additional exercises are named `Additional1_...`, `Additional2_...`, and `Additional3_...` within each unit.
- The task files are separate programs and intentionally may reuse names such as `Student`, `Car`, or `Rectangle`; run them one at a time rather than compiling every file into one target.
- Solutions include comments and sample output statements, and are designed for learning rather than production use.
